# Model Evaluation Report

## Project

Adult Income Prediction using Machine Learning

## Objective

Predict whether an individual's annual income is:

- <=50K
- >50K

## Models Evaluated

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Gradient Boosting

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Best Initial Model

Gradient Boosting achieved the best overall performance in the recorded model comparison.

- Accuracy: 0.8591
- Precision: 0.7724
- Recall: 0.5886
- F1 Score: 0.6681
- ROC-AUC: 0.9138

## Conclusion

Gradient Boosting showed the strongest overall performance among the evaluated models.
